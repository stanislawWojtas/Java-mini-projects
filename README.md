# 🤖Java-mini-projects
### This repository contains a collection of small projects that cover the fundamental aspects of Java and its key features. Each folder contains different topic:
### 📂 Matrix operations📓
This project includes basic matrix operations such as addition and scalar multiplication. It also features matrix multiplication, Frobenius norm calculation, and determinant computation for square matrices using Gaussian elimination. More important methods are getting tested by unit tests.
### 📂 Math expressions🖋️
Implementation of classes for representing simple mathematical expressions (functions of one or multiple variables) as expression trees. Expressions are not parsed from strings, but built through well-structured code. They support basic operations on constants and variables, as well as more advanced features like derivative calculation.
### 📂 CV generator👷
The project includes classes that generate sample CVs in HTML format. It also provides methods for saving to and reading from JSON format. Additionally, the project contains unit tests for some of the HTML-related classes.
### 📂 Admin units Poland🏞️
The project includes an implementation of the CSVReader class for reading CSV files in various ways, handling common issues such as missing values.
In the second part, a list of AdminUnit objects is created from a CSV file containing information about localities in Poland. The localities are organized hierarchically using parent-child relationships. The project also features:
- Sorting and filtering localities based on custom criteria (Quering the data)
- Finding neighboring localities
- Exporting the bounding boxes of localities in [WKT](https://en.wikipedia.org/wiki/Well-known_text_representation_of_geometry) (Well-Known Text) format for mapping purposes
### 📂 Clock with GUI🕐
A simple GUI-based clock application that uses threads to update the display in real time.
### 📂 Concurrent operations🔄
This project compares the performance of various methods for computing the average value, exploring both multithreaded (parallel) and single-threaded (sequential) approaches.
